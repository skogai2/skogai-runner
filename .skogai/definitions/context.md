# context

context is the set of things [[resolve]]d for a task: the closure of what
it [[requires]], with each name resolved where the task happens.

an agent's freedom lives inside its context, and the only limit on it is
what the context leaves out. there is no list of things not to do, because
anything not in the context was never there to begin with.
