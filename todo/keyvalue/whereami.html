whereami: what environment is this agent in?

An agent that starts a turn should be able to say which machine it is on, whether it is boxed in, how a human reaches it, which harness runs it and what folder it stands in. Each of those has a cheap, read-only signal. One script asks all of them and prints a line per answer.

Five layers

The question splits cleanly. Answer each layer on its own, from the most reliable signal first. A "hint" signal can be wrong in both directions, so treat it as a lead, not a fact.

layerquestionsignals, best firsttrust
machineWhich box, which OS?hostname, /etc/os-release, uname -rmsolid
isolationContainer, VM, WSL, or bare host?systemd-detect-virt -c / -v, /.dockerenv, /run/.containerenv, /proc/version for WSL, /proc/1/cgroupsolid cgroup: hint
accessHow does a human reach this shell?SSH_CONNECTION, TMUX / ZELLIJ / STY, TERM_PROGRAMsolid
agentWhich harness, which session, local or cloud?CLAUDECODE, CLAUDE_CODE_ENTRYPOINT, CLAUDE_CODE_REMOTE, session ids, messaging socketinternal, may change
workspaceWhat folder, is it git, is it throwaway?$PWD path shape, git rev-parse, git-dir vs common-dirsolid

What the shell cannot see

Some facts live only in the agent's own context: the system prompt and tool list the harness gave it. For these the agent has to report on itself, and the report belongs next to the probe output.

Model and effortOnly the system prompt names the model. CLAUDE_EFFORT covers effort.
Permission modeAuto, plan, accept-edits. Stated in the prompt, never in the env.
SandboxNo flag says it. Probe it: try a harmless write outside the workspace and see whether it fails.
Tools, MCP, skillsThe loaded tool list is context. CLAUDE_CODE_PLUGIN_STORE_DIR shows where plugins live, not which are on.
Who is watchingRemote Control relays the session to a phone through the app. agent.remote=false does not mean nobody else is reading.
Which machine a peer is onThe agent list shows kind (local, cloud, Remote Control) but not host or folder. A peer has to say so itself.

Rules the script follows

  1. Every key always prints. The default is unknown or none, never a missing line. A reader can diff two runs line by line and a missing key means a broken script, not an absent fact.
  2. One fact per line, layer.key=value. The dot is the relation. Lines can be grepped, appended to a log, or turned into JSON without a parser.
  3. Read-only and offline. It runs nothing that writes or calls out, so any agent can run it at the start of any turn without asking.
  4. Never dump the environment. A plain env in an agent shell holds an OAuth scope list, a messaging token and the account email. Name each variable you read.
  5. Internal variables are hints. The CLAUDE_CODE_* names are what this version sets, not a published contract. They fall back to a default, so a rename shows up as unknown instead of a crash.

Using it

Three shapes cover most needs. The last one answers the agent-list problem: each session appends a stamped card to a shared log, so a peer can look up where another session runs.

# one layer
bash whereami.sh | grep '^agent\.'

# as a json object
bash whereami.sh | jq -Rn '[inputs | capture("(?<k>[^=]+)=(?<v>.*)")] | from_entries'

# append-only session card: one line per run
printf '%s %s\n' "$(date -Is)" "$(bash whereami.sh | paste -sd' ')" >> .skogai/state/whereami.log

The script

Bash, no dependencies beyond coreutils. systemd-detect-virt and git are used when present.

#!/usr/bin/env bash
# whereami: answer "what environment is this agent running in?" as key=value lines.
# every key always prints; "unknown" is the default, never a missing line.
# reads only: no network, no writes, never prints secrets.

kv() { printf '%s=%s\n' "$1" "${2:-unknown}"; }
has() { command -v "$1" >/dev/null 2>&1; }

# --- machine -----------------------------------------------------------
os_id=unknown
[ -r /etc/os-release ] && os_id=$(. /etc/os-release; echo "${ID:-unknown}")
kv machine.host "$(hostname 2>/dev/null || cat /etc/hostname 2>/dev/null)"
kv machine.os "$(uname -s 2>/dev/null)"
kv machine.distro "$os_id"
kv machine.kernel "$(uname -r 2>/dev/null)"
kv machine.arch "$(uname -m 2>/dev/null)"
kv machine.user "$(id -un 2>/dev/null)"

# --- isolation: container / vm / wsl ------------------------------------
container=none
if has systemd-detect-virt; then
  c=$(systemd-detect-virt --container 2>/dev/null); [ -n "$c" ] && container=$c
fi
if [ "$container" = none ]; then
  if [ -f /.dockerenv ]; then container=docker
  elif [ -f /run/.containerenv ]; then container=podman
  elif grep -qaE 'docker|kubepods|containerd|lxc' /proc/1/cgroup 2>/dev/null; then container=cgroup-hint
  fi
fi
vm=none
if has systemd-detect-virt; then
  v=$(systemd-detect-virt --vm 2>/dev/null); [ -n "$v" ] && vm=$v
fi
wsl=no
{ [ -n "$WSL_DISTRO_NAME" ] || grep -qi microsoft /proc/version 2>/dev/null; } && wsl=${WSL_DISTRO_NAME:-yes}
kv isolation.container "$container"
kv isolation.vm "$vm"
kv isolation.wsl "$wsl"
kv isolation.pid1 "$(cat /proc/1/comm 2>/dev/null)"

# --- access: how a human reaches this shell -----------------------------
ssh=no; [ -n "$SSH_CONNECTION" ] && ssh=yes
kv access.ssh "$ssh"
kv access.multiplexer "$( [ -n "$TMUX" ] && echo tmux || { [ -n "$ZELLIJ" ] && echo zellij; } || { [ -n "$STY" ] && echo screen; } || echo none)"
kv access.terminal "${TERM_PROGRAM:-${TERM:-none}}"

# --- agent harness -------------------------------------------------------
agent=none; [ "$CLAUDECODE" = 1 ] && agent=claude-code
kv agent.harness "$agent"
kv agent.entrypoint "${CLAUDE_CODE_ENTRYPOINT}"           # observed: claude-desktop, cli
kv agent.remote "${CLAUDE_CODE_REMOTE:-false}"            # set in cloud (web) sessions
kv agent.version "$(basename "$(dirname "$(dirname "${CLAUDE_CODE_EXECPATH:-/x/unknown/x/x}")")")"
kv agent.sdk_version "${CLAUDE_AGENT_SDK_VERSION}"
kv agent.desktop_version "${CLAUDE_CODE_DESKTOP_APP_VERSION:-none}"
kv agent.session_id "${CLAUDE_CODE_SESSION_ID}"
kv agent.host_session_id "${CLAUDE_CODE_HOST_SESSION_ID:-none}"
kv agent.child_session "${CLAUDE_CODE_CHILD_SESSION:-0}"
kv agent.attended "${CLAUDE_CODE_SESSION_ATTENDED:-unknown}"
kv agent.effort "${CLAUDE_EFFORT}"
kv agent.messaging_socket "$( [ -S "$CLAUDE_CODE_MESSAGING_SOCKET" ] && echo present || echo none)"

# --- workspace -----------------------------------------------------------
kv workspace.cwd "$PWD"
case "$PWD" in
  */scratch-workspaces/*) ws=scratch ;;
  */worktrees/*|*/.worktrees/*) ws=worktree ;;
  *) ws=folder ;;
esac
kv workspace.kind "$ws"
if has git && git rev-parse --is-inside-work-tree >/dev/null 2>&1; then
  kv workspace.git yes
  kv workspace.git_root "$(git rev-parse --show-toplevel)"
  kv workspace.git_branch "$(git branch --show-current 2>/dev/null)"
  kv workspace.git_linked_worktree "$( [ "$(git rev-parse --git-dir)" != "$(git rev-parse --git-common-dir)" ] && echo yes || echo no)"
else
  kv workspace.git no
  kv workspace.git_root none
  kv workspace.git_branch none
  kv workspace.git_linked_worktree no
fi
